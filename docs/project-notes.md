# プロジェクトメモ

KK Lingo は、PDFをもとに復習問題を生成し、保存・共有できる学習支援システムです。実装上は、Webアプリ、DB API、LLM APIを分けて管理しています。

## 設計上のポイント

- LLMによる問題生成と、DBへの保存・検索を別サービスに分けている。
- Next.js API RoutesをBFFとして使い、ブラウザから内部APIキーを直接扱わない。
- LLM APIはDBに依存せず、DB APIはGeminiに依存しない。
- monorepoにすることで、システム全体の構成を1つのリポジトリで追いやすくしている。

## 現在できること

- PDFをもとにした問題生成
- 生成された問題の保存
- 問題の検索・閲覧
- 作成者による問題編集・削除
- ユーザー作成、ログイン、簡易的な管理画面
